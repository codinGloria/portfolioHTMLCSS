Este repositório foi criado como parte de uma atividade prática do curso de desenvolvimento web (Anteriormente, utilizado para um projeto de Desenv. Front End na faculdade). Agora, atualizado, o objetivo é construir uma página de perfil pessoal utilizando boas práticas de estruturação, responsividade e estilização.

## 📂 Sobre o Projeto

A proposta é desenvolver uma página estática com:

- Um cabeçalho com nome e imagem pessoal.
- Navegação por âncoras para facilitar o acesso às seções da página.
- Conteúdo principal dividido em blocos como Sobre mim, Habilidades, Projetos e Contato.
- Rodapé com créditos e informações adicionais.

Além disso, o projeto usa:

- Tags semânticas como `<header>`, `<main>`, `<section>`, `<article>`, `<aside>` e `<footer>`.
- Flexbox e CSS Grid para o layout responsivo.
- Pseudo-classes e pseudo-elementos para estilização avançada.
- Variáveis CSS e media queries para garantir um visual moderno em diferentes telas.
